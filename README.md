## 🚀 Como executar

### Pré-requisitos

- [.NET SDK](https://dotnet.microsoft.com/download) instalado

### Passo a passo

```bash
# Clone o repositório
git clone https://github.com/EduardoWandermurem25/Ficha-do-Her-i.git

# Acesse a pasta do projeto
cd Ficha-do-Her-i

# Execute a aplicação
dotnet run
```
